# Contributing

This is a **template**. Fork or clone it and make it your hub. PRs that improve the generic scripts, skills, or docs are welcome.

- Do not add a personal `SOUL.md` / client `repos.json` to this upstream.
- Keep secrets out of git.
- Shell scripts: `set -euo pipefail`; never force-reset foreign dirty trees.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
